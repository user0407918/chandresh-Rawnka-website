# Chandresh Rawka Website

Production-ready static website for Chandresh Rawka, AMFI Registered Mutual Fund & SIF Distributor.

## Hosting

This project is static HTML/CSS and can be deployed directly to Vercel, GitHub Pages, Netlify or any standard static host.

## Pages

- Home
- Commission Disclosure
- Risk Factors
- Investor Charter
- Grievance Redressal
- Registration Disclosure
- Privacy Policy
- Terms & Conditions
- Disclaimer

The Vercel configuration enables clean URLs and basic browser security headers. Before public launch, verify all regulatory credentials, contact details and disclosure wording against the latest official records and approved client documents.
